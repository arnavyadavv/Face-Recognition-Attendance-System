# Face Recognition Attendance System

An AI-based attendance management system that automates student attendance using real-time facial recognition.

## Features

* Real-time face detection and recognition
* Automatic attendance marking
* CSV-based attendance logging
* Optimized webcam processing
* Confidence-based face matching

## Technologies Used

* Python
* OpenCV
* face_recognition
* NumPy

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Add training images inside:
   Training_images/

3. Run the project:
   python main.py
